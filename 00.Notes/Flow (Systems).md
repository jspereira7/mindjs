## O que é Flow ? 

Todo sistema tem fluxos ou flows: Movimentos de recursos para dentro e para fora do sistema. 

***inflows*** são recursos que entram no sistema, como a água em uma pia, ***Outflows*** são recursos saindo do sistema, como dinheiro saindo de uma conta bancaria. 

Entenda os fluxos para entender o sistema.

------
## Explicação

Não importa qual sistema faça, ele terá fluxos-movimentos de recursos entrando e saindo do sistema. 

Imagine uma linha de montagem automotiva: ferros, aço, plastico entram isso é o input do sistema, o carro pronto é o output.

***inflows(Entradas)*** são os recursos entrando para o sistema: 
- Agua em uma pia
- Dinheiro em uma conta bancaria
- Materias primas em uma linha de montagem
- Novos contratados em uma empresa

***Outflows(saidas)*** são recursos que saem de um sistema: 
- Agua sendo drenada de uma pia
- Dinheiro saindo de uma conta bancaria
- Produtos acabados saindo de uma linha de montagem
- Funcionarios que saem da empresa devido a aposentadoria, demisão ou mudança de emprego

Siga os fluxos e vc estará no caminho certo para entender como o sistema funciona.
