
## O que é Medir ? 

Medição é o processo de coleta de dados à medida que o sistema opera. A medição também permite comparar sistemas entre si.

A melhor maneira de evitar Cegueira de Ausência é medir para identificar possíveis problemas que você pode não estar vendo.

O primeiro passo para melhorar um sistema é coletar dados, e você faz isso com Medição.

------
## Explicação

Depois de entender as partes do sistema e como elas interagem entre si, vale a pena fazer outra pergunta: quão bem o sistema está operando? Para fazer isso, contamos com a medição do sistema enquanto ele está operando.

Medição é o processo de coleta de dados à medida que o sistema está operando. Ao coletar informações relacionadas às funções principais do sistema, é muito mais fácil entender exatamente o desempenho do próprio sistema.

A medição também permite que os sistemas sejam comparados entre si. Por exemplo, é possível usar vários tipos diferentes de microprocessadores para construir um computador - qual você deve usar? Ao medir várias características de cada tempo de ciclo do processador, consumo de energia, geração de calor, etc., é possível escolher o melhor processador para seu computador, resultando em melhor desempenho.

Lembre-se: temos dificuldade em ver coisas que não estão presentes. Medir diferentes partes de um sistema em operação ajuda a identificar possíveis problemas antes que eles surjam.

Por exemplo, o diabetes é uma condição que representa uma falha no Loop de feedback que controla os níveis de glicose no sangue do corpo. 
- Muita ou pouca glicose no sangue é fatal, portanto, se o corpo produz muita ou pouca insulina para manter os níveis de glicose no sangue estáveis, esse é um grande problema.

Embora os níveis de insulina sejam extremamente importantes para uma pessoa com diabetes, você não consegue descobrir o nível de insulina ou glicose no sangue de uma pessoa apenas observando-a.

***Medir algo é o primeiro passo para melhorá-lo. Peter Drucker opinou: “O que é medido é gerenciado.” É verdade.***

Se você não sabe quanto dinheiro sua empresa está arrecadando ou gastando, é difícil saber se alguma mudança que você faz em seu sistema de negócios é realmente uma melhoria.

Se você quer perder peso, primeiro precisa saber quanto pesa agora e depois monitorar como quaisquer mudanças feitas afetam seu peso.

Sem dados, você fica cego. Se você quiser melhorar alguma coisa, você deve medi-la primeiro.
