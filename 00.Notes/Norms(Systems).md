
## O que é Norms ? 

Normas são medidas que usam dados históricos para fornecer Contexto para medições de corrente. São uma forma de aprender com o passado para evitar erros anteriores.

Quando as práticas de medição mudam, Normas com base nas medições anteriores não são mais válidos. Mudar os métodos de medição, e você invalida qualquer Normas com base neles.

O desempenho passado não é garantia de desempenho futuro. Examine o seu Normas para ter certeza de que são válidos.

------
## Explicação

Por exemplo, ao analisar dados anteriores, você pode descobrir que a sazonalidade é um bom exemplo de por que as normas geralmente são úteis.

Lembre-se, estamos lidando com sistemas complexos - coisas sempre Mudar com o tempo. Só porque algo foi útil no passado não significa que continuará a ter um desempenho tão bom para sempre.

Para melhores resultados, reexamine seu Normas periodicamente para garantir que sejam válidos.
