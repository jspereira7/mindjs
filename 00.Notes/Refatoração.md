
## O que é Refatoração ? 

Refatorar significa mudar o sistema para melhorar a eficacia dele sem mudar o output.

Melhorar o output não é o objetivo de refatorar. 

O objetivo é apenas tornar o sistema mais rapido e mais eficiente.

Refatorar começar desconstruindo o sistema e depois procurando padrões. 

Quando os padrões emergem, vc pode rearanjar o sistema reagrupando processos similares e inputs juntos. Refatorar é critico pra melhorar a funcionalidade de qualquer sistema

------
## Explicação

Nem todas as alterações em um sistema são projetadas para afetar a saída do sistema. Às vezes, é mais eficaz reprojetar um processo sem alterar o resultado final.

_Refatoração_ é o processo de alterar um sistema para melhorar a eficiência sem alterar a saída do sistema.

O termo vem de programação de computadores: programadores passam horas reescrevendo um programa que, se tudo correr bem, faz exatamente a mesma coisa quando termina. Qual é o sentido?

O principal benefício de Refatoração não está melhorando a saída - está tornando o próprio sistema mais rápido ou mais eficiente. 

Ao reorganizar os processos que o sistema usa para produzir o resultado, é possível fazer com que o programa seja executado mais rapidamente ou exija menos recursos durante a operação.

Refatoração começa por Desconstruindo um processo ou sistema, procurando então Padrões.

Quais são os processos críticos que absolutamente devem ser feitos corretamente para atingir o objetivo desejado? Esses processos precisam ser concluídos em uma determinada ordem? Quais são as restrições atuais? O que parece ser particularmente importante? Colete o máximo de informações possível sobre como o sistema funciona e depois fique sentado com ele por um tempo.

Na maioria das vezes, você começará a notar coisas no sistema que não fazem sentido — coisas que você fez de uma certa maneira porque pareciam uma boa ideia na época, mas não são a melhor maneira de abordar a tarefa agora.

Pense em reorganizar uma linha de montagem: se você tem que parar constantemente o que está fazendo e viajar por toda a fábrica para obter uma peça, reorganizar as coisas para que a peça esteja sempre por perto provavelmente é uma boa ideia.

O sistema ainda produzirá a mesma coisa quando você terminar, mas você terá removido as pequenas ineficiências do sistema que resultam em perdas significativas de produtividade.

Se seu objetivo é tornar o sistema mais rápido ou eficiente, a refatoração é extremamente importante.
