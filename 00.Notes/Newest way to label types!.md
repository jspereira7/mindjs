I always hated how verbose the nomenclature was for the Octagram when it came out. There are only 4 varients, yet were typing 4 damn letters for every single one just to denote a SUBTYPE.

Once UCT came out I realized that I have now clearly defined all 8 sub-types by including gender! yay! I went from typing ENTP to -> ENTP SDSF to -> M ENTP SDSF (to add gender) but that format didn't catch on... it was too verbose and too many characters to type.

Below... I found a super simple solution!

## How to read and write sub-types the quickest and most effective way

8 sub-types, 8 functions, 8 different primary functions... easy enough, lets just enumerate them 1 to 8! super simple.

`M ENTP SDSF (Si primary)` -> `ENTP4` (4 denotes the 4th function, or aka the inferior) _*(read how to calculate primaries in the next section)_

examples: 

``ENTP1 = UDSF Female  // Hero Primary
``ENTP2 = UDSF Male    // Parent Primary
``ENTP3 = SDSF Female  // Child Primary
``ENTP4 = SDSF Male    // Inferior Primary
``ENTP5 = SDUF Male    // Nemesis Primary
``ENTP6 = SDUF Female  // Critic Primary
``ENTP7 = UDUF Male    // Trickster Primary
``ENTP8 = UDUF Female  // Demon Primary``

one more example, for an ISFP it would be:

``ISFP1 = UDSF Male    // Hero Primary
``ISFP2 = UDSF Female  // Parent Primary
``ISFP3 = SDSF Male    // Child Primary
``ISFP4 = SDSF Female  // Inferior Primary
``ISFP5 = SDUF Female  // Nemesis Primary
``ISFP6 = SDUF Male    // Critic Primary
``ISFP7 = UDUF Female  // Trickster Primary
``ISFP8 = UDUF Male    // Demon Primary

## How to calculate primaries

For those who don't know, its simple:

Memorize this order:
``UDSF(EGO)
``SDSF(SUB)
``SDUF(UNC)
``UDUF(SUP)

now, realize once you point to any side of the mind, there are two functions, the introverted one is the male's primary, extroverted is the females primary

A introvertida é a principal do homem, a extrovertida é a principal da mulher. 

**ISFP 4:** 
- Fi Hero = Simpatia, valores (Tem orgulho do que valoriza)
- Se Parent = Demonstração, Performance (É irresponsalvel, cortando atalhos)
- Ni Child = Determinação, escolher (Fica magoada se susa escolha é tirada)
- Te Inferior = Entender, status, reputação (Ela tem medo do que os outros vão pensar)
- Fe Nemesis = Empatia (Está preocupada que não se importem o suficiente)
- Si Cynic = É tolo sobre o que lembra 
- Ne trickster = Não tem conciencia das consequencias
- Ti Demon = Rejeita a verdade em favor da crença pessoal
