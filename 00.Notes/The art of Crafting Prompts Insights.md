
# Peça para a Ai, diferentes niveis de entendimento
---


> Diga para o modelo o seu nivel atual de entendimento sobre o assunto 

Dessa forma ele consegue te dar respostas que você consegue entender melhor. 

Dessa forma, você ajuda a Ai dar a resposta que será mais relevante para você

Você pode usar essa estrategia, para encontrar formas simples de explicar um tópico para alguem, ou até mesmo para aprender melhor. 



----

### Exemplos de prompt: 

- **Iniciante no assunto:**
```
Sou novo no chatgpt e Ai, me de um overview do que é o chat gpt e como ele funciona, explique como se eu tivesse 5 anos

```

**NivelPHD**

```
Agora me explique como se eu tivesse um PHD na area da ciencia da computação
```

**Termos simples, com explicações dos jargoes técnicos**
```
Explique o que é o chatgpt em termos simples, e caso precise usar jargoes técnicos, me explique o que eles são
```
