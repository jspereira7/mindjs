## O que é  ? 

O desempenho de um sistema é limitado pela disponibilidade de entrada crítica. Elimine o ***Gargalo*** e o desempenho melhorará.

Estas são as cinco etapas de Goldratt para aliviar uma restrição:
1. Encontrar o fator limitante
2. Exploração: certificar-se de que os recursos relacionados a restrição não são desperdiçados.
3. Subordinação: redesenhar o sistema pra suportar a Restrição
4. Elevação: Elevar a capacidade de Restrição
5. Reavaliação: depois de fazer uma alteração, reavalie um sistema para ver onde está a Restrição.

Quanto mais rápido vc passar por essas etapas mais rápido a taxa de transferencia irá melhorar. 

------
## Explicação

O desempenho de um sistema é sempre limitado pela disponibilidade de uma entrada crítica.

Alivie a restrição e o desempenho irá melhorar. 

Em O Objetivo: Um Processo de Melhoria Contínua, Eliyhu Goldratt explica o que ele chama de “Teoria das Restrições”: qualquer sistema gerenciável é sempre limitado em atingir mais de seu objetivo por pelo menos uma restrição.

Se você puder identificar a restrição e aliviá-la, é possível aumentar o Taxa de transferência do sistema.

Criar ou aumentar o tamanho de um Estoque diante de uma restrição pode ajudar a aliviar o problema. Se você está constantemente ficando sem motores, aumentar a folga no estoque do motor é a melhor maneira de aliviar a restrição. Ao garantir que a restrição não seja “privada”, você pode aumentar o desempenho de todo o sistema.

Para encontrar e aliviar uma restrição, Goldratt propõe as “Cinco Etapas de Foco”, um método que você pode usar para melhorar o rendimento de qualquer sistema:

1. Identificação: examinar o sistema para encontrar o fator limitante. 
2. Exploração: garantir que os recursos relacionados à restrição não sejam desperdiçados.
3. Subordinação: redesenhar todo o sistema para suportar a restrição.
4. Elevação: aumento permanente da capacidade da restrição.
5. Reavaliação: após fazer uma alteração, reavaliar o sistema para ver onde a restrição está localizada.
