
## O que é proxy ? 

Um proxy mede uma quantidade, medindo outra coisa. Pense nos votos: eles medem a "vontade" do povo, por mais que medi-la com 100% de precisão seja impossivel.

Quanto mais próximo o Proxy ao assunto relacionado, mais preciso.

Os proxies podem ajudar a medir o imensurável, mas você tem que ter certeza de que o Proxy está altamente correlacionado com o assunto de interesse.

------
## Explicação

O que você faz se não for possível medir algo diretamente? Um Proxy mede uma quantidade medindo outra coisa.

Quanto melhor, melhor Correlação, quanto melhor o Proxy. Para obter melhores resultados, certifique-se de que o proxy esteja realmente relacionado ao assunto pretendido.

Os proxies podem ser complicados ou enganosos se parecem medir uma coisa, mas na verdade medem outra. Pense no exemplo de tentar medir a produtividade do programador contando linhas de código como um Indicador-chave de desempenho.

Como discutimos anteriormente, “linhas de código” é certamente uma Proxy para eficácia de programação, mas mais código às vezes é um sinal inverso de produtividade, tornando-se uma medida inútil para o objetivo declarado.

Usados com cuidado, os proxies podem ajudá-lo a medir o imensurável - apenas certifique-se de que seu proxy seja direto e altamente Correlacionado com o assunto de interesse.
