
## O que é Fail Safe ? 

*Fail safe* é um sistema de bakup projetado para prevenir ou permitir a recuperação de uma falha primária do sistema. 

As proteções contra falhas não são eficientes se você acha que nunca precisará delas. O problema é que, se você precisar de um, será tarde demais para desenvolvê-lo. As proteções contra falhas devem ser desenvolvidas antes de serem necessárias.

Separe seu Fail-safe do seu sistema primário o máximo possível para evitar que uma tragédia estrague tudo.

Nunca torne o sistema de backup parte do sistema que você está tentando proteger. Interdependência não é bom quando se trata de Fail-safes.

Tente eliminar pontos únicos de falha. Se o sistema depende de entradas críticas para funcionar, você deve planejar quando essas entradas não estiverem disponíveis.


------
## Explicação

Sistemas de backup e Seguro, de uma perspectiva, pode ser visto como um desperdício de dinheiro - por que gastar recursos valiosos em algo que você espera nunca precisar? Eis o porquê: no momento em que você precisa de um Fail-Safe, é tarde demais para desenvolver um.

Para serem eficazes, os Fail-Safes devem ser desenvolvidos antes que você precise deles. Se você esperar para desenvolver sistemas de backup até precisar deles, é tarde demais para fazer a diferença.

Pagar pelo seguro residencial pode parecer um desperdício de dinheiro até que sua casa pegue fogo. Se você esperar para comprar um seguro até que algo ruim aconteça, já é tarde demais.

A prática de fazer backup de dados em um data center externo tem a mesma finalidade: se algo acontecer com os computadores comerciais, os dados ainda estarão seguros em outro local.

O que você faria se o sistema falhasse? Planeje com antecedência o desenvolvimento de dispositivos de segurança contra falhas para todos os sistemas críticos e você fará seu sistema como Resiliente como você possivelmente pode.
