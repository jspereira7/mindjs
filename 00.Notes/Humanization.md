
## O que é Humanização ? 

Humanização é o processo de usar dados para contar uma história (Narrativa) sobre a experiência ou comportamento de uma pessoa real.

Os números contam apenas parte da história, você precisa reformular as medidas em comportamento real para realmente entender o que acontece.

Desenvolver perfis fictícios de pessoas desenvolvidos a partir de dados (chamados “personas”) é uma ótima maneira de Humanizar.

Apenas dados não significam muito. Conte uma história para ajudar as pessoas a entender os problemas.

------
## Explicação

Analisar dados é reconfortante para quem tem uma mentalidade quantitativa, mas para realmente usá-los corretamente, você precisa ir além de manipular números para entender o que eles estão lhe dizendo. Ao analisar dados de um sistema, é fácil esquecer que eles geralmente dizem respeito às ações de seres humanos reais.

Humanização é o processo de usar dados para contar uma história (Narrativa) sobre a experiência ou comportamento de uma pessoa real.

Medidas quantificáveis são úteis em conjunto, mas muitas vezes é necessário abstrair a medida em comportamento real para realmente entender o que está realmente acontecendo. Muitas empresas Humanizar desenvolvendo uma série de personas: perfis fictícios de pessoas desenvolvidos a partir de dados.

Uma vez desenvolvido o perfil, ficou mais fácil usar os dados que tínhamos para tomar decisões - em vez de depender de estatísticas para avaliar uma ideia, podíamos confiar em nossa intuição nos perguntando se “Wendy” gostaria disso.

Não apresente apenas dados - conte uma história que ajude as pessoas a entender o que está acontecendo, e você achará seus esforços de análise mais úteis.
