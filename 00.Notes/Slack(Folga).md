Slack é a quantidade de recursos presentes em um Stock.

## Explicação

Slack ou folga é a quantidade de recursos presentes em um estoque, quanto mais recursos você tiver em um estoque, mais Slack vc terá. 

Para um sistema operar de forma eficiente, os estoques devem ter o tamanho correto, nem muito grande, nem muito pequeno.

Pense no nosso hipotético sistema de fabricação automotiva: é uma combinação de muitos sistemas menores, cada um dos quais é projetado para criar um estoque de peças.

Se não houver Estoque de motores esperando para serem instalados quando um carro chega àquela parte da linha de montagem, isso é um problema: o carro terá que esperar até que um motor esteja pronto, o que mantém tudo alinhado atrás dele.

Para evitar esse problema, é melhor garantir o **Estoque** é grande o suficiente para lidar com o nível de saídas necessárias para manter o sistema funcionando.

Folga é complicado de administrar: é demais e você está desperdiçando tempo e dinheiro. Muito pouco, e seu sistema corre o risco de ficar sem os recursos necessários para continuar operando.
