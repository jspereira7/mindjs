## O que é Margem de erro ? 

_Margem de erro_ é uma estimativa de quanto você pode confiar em suas conclusões a partir de um determinado conjunto de observações _Amostras_.

Amostras pequenas podem levar a medições enganosas. Colete sempre as maiores amostras possíveis para garantir melhores resultados.

------
## Explicação

A matemática por trás de como calcular intervalos de confiança está além do escopo deste livro, mas é relativamente fácil quando você pega o jeito, principalmente se você usa uma planilha ou banco de dados para sua análise.

Quando se trata de confiança analítica, mais dados são sempre melhores - colete as maiores amostras que puder.
