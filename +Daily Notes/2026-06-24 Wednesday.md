## The feynman techinich to learn 

Prompt 1: 

```

Acabei de terminar de ler sobre [TÓPICO].
Quero aplicar o Método Feynman para garantir que isso realmente fique na minha cabeça.

Passo 1: Mapa de Conceitos.
Liste as 5 ideias mais importantes desse tópico que eu preciso entender completamente.

Para cada ideia, me dê:
- A definição em 1 frase, em português simples
- Por que essa ideia importa no mundo real
- 1 pergunta que eu deveria conseguir responder se eu realmente entendi ela

Não use jargão. Não assuma que eu tenho conhecimento prévio nessa área.
Escreva como se estivesse explicando para um adolescente inteligente de 16 anos.

```

## How to learn better with ai 

Prompt1 - Build a learning ladder: 
```
Quero aprender [tópico], indo do nível iniciante até adquirir um conhecimento prático e funcional. Crie uma escada de aprendizado de 5 níveis. Para cada nível, explique o que devo compreender, o que devo ser capaz de fazer e quais são as confusões comuns nessa etapa.

```

Prompt 2 - Create a study plan: 
```
Transforme este tópico em um plano de aprendizado de [7 dias / 14 dias / 20 horas]. Mantenha-o prático, progressivo e adequado para iniciantes. Inclua o que estudar, o que praticar e como acompanhar o progresso.
```

Prompt3 - Teach one concept clearly: 
```
Explique-me o conceito de [conceito] usando uma linguagem simples. Comece pela intuição, passe para um exemplo prático e termine com um exercício rápido. Evite jargões, a menos que você os explique.
```

Prompt4 - Quiz Me: 
```
Faça um quiz para mim sobre [tópico]. Use 10 perguntas. Combine questões de memorização, compreensão e aplicação. Não revele as respostas até que eu responda.
```

Prompt5 - Build a cheat sheet
```
Crie uma folha de consulta de uma página sobre [tópico]. Inclua as ideias mais importantes, os erros comuns e o que devo lembrar durante a revisão.
```

Prompt6 - Feyman Technick
```
Vou explicar [tópico] em termos simples. Sua função é agir como um iniciante inteligente e questionar explicações fracas, redações vagas e etapas ausentes. Ajude-me a identificar o que eu realmente não compreendo.
```
